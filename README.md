# Practice: Array Methods

## Project Description
This project focuses on using built-in JavaScript **Array Methods** to manipulate and query data. It is part of the **LaunchCode Foundations of Software Development** curriculum. 

The exercise covers essential methods for adding/removing elements, searching arrays, combining datasets, and reorganizing information through sorting.

## Key Learning Objectives
* **Push/Pop & Shift/Unshift:** Adding and removing elements from the start and end of arrays.
* **Searching:** Using `includes()`, `indexOf()`, and `lastIndexOf()` to find data.
* **Array Transformation:** Using `concat()` to combine arrays and `slice()` vs `splice()` for extraction and replacement.
* **Ordering:** Implementing `sort()` and `reverse()` to manage data hierarchy.

## Methods Demonstrated
* `push()`, `shift()`, `unshift()`
* `includes()`, `indexOf()`, `lastIndexOf()`
* `concat()`
* `slice()`, `splice()`
* `sort()`, `reverse()`
